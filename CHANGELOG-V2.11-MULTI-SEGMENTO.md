# LG Agenda V2.11 - Multi-segmento

## O que mudou
- LG Agenda deixou de se posicionar apenas para barbearias.
- Página de venda agora atende barbearias, salões de beleza, manicure/nail designer, estética, pet shops/banho e tosa e outros negócios de serviços.
- Onboarding pergunta o tipo de negócio.
- Tipo de negócio também pode ser alterado em Estabelecimento.
- Textos e exemplos internos foram neutralizados.
- Default de função de profissional passou de `Barbeiro` para `Profissional`.

## Banco de dados
Execute `supabase/migration-v2.11-multi-segmento.sql` uma vez no SQL Editor do Supabase antes de usar o novo campo em produção.
